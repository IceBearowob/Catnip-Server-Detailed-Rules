## 規範範圍

浪潮、天界的代打服務

## 強制性紀錄事項
- 代打時段:在代打店面公告代打開始及結束時間
- 代打時間戳:紀錄代打場次開始的時間
- 代打人:實際在該代打場次打單的玩家
- 委託人(就是下單的人)
- 掉落物
### 舉例:
```
第一場 - 2026/8/24 00:41:38 
代打人: Ice_CatBear
服務對象: Ice_CatBear
掉落物: 獻祭經驗、自修、迅捷潛行
```
## 選擇性紀錄事項
下列可以作為有服務爭議時的證據使用:
- 錄影(OBS、Flashback、Replay mod):必須包含完整從進入場控到退出場控
- 直播代打(服務對象需要在場):在代打場次進行時不能中斷
## 原則
1. 如果有服務爭議，以代打時段與代打時間戳為準判定場次
2. 如果不依照本條文中強制性事項紀錄，伺服器方得判定其契約無效
3. 代打時段的公告不可有編輯紀錄
4. 強制性紀錄事項應保持公開
