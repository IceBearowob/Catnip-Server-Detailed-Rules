# 玩家領地凍結處置方法

## 申請條件

1. 在檢舉事件結案且確定UR後才會受理
2. 申請解凍的領地不可為包含複製品或不當獲得的物品的領地
3. 申請方應主動提供該領地為共同使用或建造關係的證據，如果不完全會由 @行政 提醒補繳或者請 @系統貓 查詢資料

## 原則

1. 玩家在UR判決確定並懲處後，玩家資料與領地會完全凍結
2. 優先補償受害者的損失，其次才受理朋友或社區成員的領地解凍申請
3. 申請解凍通過後，會將領地解凍並刪除，申請方應於7日內宣告該領地，如果無理由未於時限內宣告會依貓芽規則懲處外，將領地凍結並永久拒絕其解凍申請
4. 申請方應主動將被UR懲處的玩家的物品交給 @system.cat 回收，如果無理由未主動繳回會依貓芽規則懲處外，將領地凍結並永久拒絕其解凍申請
