# 檢舉須知

## 關於檢舉玩家的使用
1. [檢舉玩家](https://discord.com/channels/1278590147193081947/1385036894424924170)為唯一合法檢舉玩家的地方
> 私下檢舉不在此限，但案件會記錄在[檢舉玩家](https://discord.com/channels/1278590147193081947/1385036894424924170)
3. 檢舉為最終玩家糾紛處理管道，建議玩家先溝通再檢舉
4. 檢舉貼文應包含
   - 被檢舉人ID
   - 檢舉原因/檢舉事由 

## 關於懲處判定與事件處理
1. @行政 為[檢舉玩家](https://discord.com/channels/1278590147193081947/1385036894424924170)案件的主要受理、調查、懲處判定者
2. 如果 @行政 事件超過一天以上沒有回應或者特殊理由，則 @行政 可以直接進行懲處判定
3. 檢舉事件處理流程:檢舉->行政初次投票/案件調查->執行行政初次投票結果->玩家投票+玩家回饋(->行政再次投票)->結案
> 如果玩家投票=行政初次投票，按照投票結果結案
> 如果玩家投票>或<行政初次投票，則行政會再次投票，最終以行政投票(討論)結果為定案
4. 貓芽得不受理私下糾紛，僅就貓芽範圍內調查處置

## 其他事項

* 如果需要匿名檢舉，或者不想讓被檢舉人知道是誰檢舉，可以透過私下檢舉來檢舉玩家
> 請私訊 @行政 並寫好被檢舉人ID與檢舉原因   
> 在檢舉確定成立後，會將檢舉案件放在[檢舉玩家](https://discord.com/channels/1278590147193081947/1385036894424924170)，部分與檢舉人或證人相關資訊會消去或者匿名處理   
* 如果因為玩家被UR，導致共同建築或居住的領地被凍結無法使用，可以按照[玩家領地凍結處置方法](https://discord.com/channels/1278590147193081947/1518115442646974564)在[詢問行政](https://discord.com/channels/1278590147193081947/1514810277827448882)申請解凍
* 對於懲處有異議者可以在[詢問行政](https://discord.com/channels/1278590147193081947/1514810277827448882)進行[申訴](https://discord.com/channels/1278590147193081947/1518114427940114493)
* 如果被檢舉人被UR或者消極處理以致無法損害賠償時，可以在[詢問行政](https://discord.com/channels/1278590147193081947/1514810277827448882)進行[損害賠償申請](https://discord.com/channels/1278590147193081947/1518114427940114493)
